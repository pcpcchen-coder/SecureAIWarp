# thumbs.sh：圖片／影片縮圖與總覽圖

`thumbs.sh` 會掃描一個資料夾裡混在一起的圖片和影片：

- **圖片**：縮到指定寬度，維持比例（比指定寬度小的圖不放大）。
- **影片**：擷取**影片長度一半處**的那一格，再縮到指定寬度。
- **總覽圖**：把所有縮圖拼成一張 `overview.jpg`，每張下方標上原始檔名。
- **已經做過的不重做**：縮圖已存在且比原始檔新時就略過；原始檔被修改後才會重做。

## 需求

- bash 4 以上
- ffmpeg / ffprobe
- ImageMagick 6 或 7（要有 `convert`、`montage`、`identify` 指令）

## 用法

```bash
./thumbs.sh [選項] 輸入資料夾 輸出資料夾
```

| 選項 | 說明 | 預設 |
|------|------|------|
| `-w 寬度` | 縮圖寬度（像素） | 320 |
| `-c 欄數` | 總覽圖每列放幾張 | 5 |
| `-o 檔名` | 總覽圖檔名（存在輸出資料夾裡） | `overview.jpg` |
| `-f` | 強制重做所有縮圖和總覽圖 | 關 |
| `-q` | 安靜模式，只印錯誤 | 關 |
| `-h` | 顯示說明 | |

範例：

```bash
# 縮圖寬 240、總覽圖每列 4 張
./thumbs.sh -w 240 -c 4 ~/Pictures/trip ~/Pictures/trip-thumbs

# 之後加了新照片，再跑一次只會補做新的
./thumbs.sh -w 240 -c 4 ~/Pictures/trip ~/Pictures/trip-thumbs
```

輸出範例：

```
產生（image）: a.jpg -> a.jpg.jpg
產生（image）: b.png -> b.png.jpg
產生（video）: c.mp4 -> c.mp4.jpg
產生總覽圖: /home/me/trip-thumbs/overview.jpg（3 張）
完成：新產生 3、略過 0、失敗 0
```

## 輸出規則

- 縮圖一律是 JPEG，檔名為「原檔名 + `.jpg`」，例如 `IMG_01.png` → `IMG_01.png.jpg`、`clip.mp4` → `clip.mp4.jpg`。保留原副檔名，`a.jpg` 和 `a.png` 就不會互相覆蓋。
- 透明背景會轉成白底；動畫 GIF 和多頁 TIFF 只取第一張。
- 影片縮圖的高度會調成偶數（ffmpeg 的要求），所以和原比例可能差 1 像素。
- 如果在影片中間點取不到畫面，會改取第一格。
- 總覽圖只包含輸入資料夾裡**目前還在**的檔案。有新縮圖、或有原始檔被刪除時才重做總覽圖，否則略過。
- 輸出資料夾會另外存一個隱藏檔 `.overview.list`，記錄上次總覽圖包含哪些縮圖。
- 縮圖會先寫到暫存檔，成功後才改名。中途中斷也不會留下半張縮圖被當成「已做過」。

## 支援的副檔名（不分大小寫）

- 圖片：jpg jpeg png gif bmp webp tif tiff
- 影片：mp4 mov mkv avi webm m4v mpg mpeg wmv flv 3gp

其他檔案和隱藏檔（`.` 開頭）會被忽略。只處理輸入資料夾的第一層，不會進入子資料夾。

## 結束碼

| 碼 | 意義 |
|----|------|
| 0 | 全部成功（包含沒有可處理的檔案） |
| 1 | 有檔案處理失敗（例如壞檔）。失敗的檔案會被跳過，其他檔案照常處理 |
| 2 | 參數錯誤，或輸入資料夾不存在 |
| 3 | 缺少 ffmpeg 或 ImageMagick |

## 測試

```bash
tests/run_tests.sh
```

測試用的圖片和影片都是現場用 ImageMagick 和 ffmpeg 產生，不需要網路。其中包括一段「紅→綠→藍」各 1 秒的影片，用來驗證擷取的確實是中間那一格（綠色）。暫存資料放在 `tests/.work.*`，跑完會自動刪除；要放到別的位置可以設定 `THUMBS_TEST_TMP=/某個/資料夾`。

測試涵蓋以下情況：

- 參數錯誤
- 縮圖寬度和比例
- 影片取中間一格
- 忽略非媒體檔
- 總覽圖的產生與更新
- 已做過的不重做、原始檔更新後重做、新增或刪除檔案
- `-f`、`-q`、`-c`、`-o` 選項
- 特殊檔名：空白、`%`、中文、`-` 開頭、大寫副檔名、同名不同副檔名
- 小圖不放大
- 透明背景和動畫 GIF
- 壞檔
- 空資料夾
